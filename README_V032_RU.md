# StandEL Time v0.32 — установка на телефон (PWA)

Основано на v0.31. Новых миграций Supabase нет.

## Что добавлено
- /manifest.webmanifest — PWA-манифест для StandEL Time.
- Логотип-иконка StandEL, 192/512 px, маскируемая иконка и Apple Touch Icon.
- Service Worker, который кэширует **только публичные статичные иконки и логотип**. Не кэширует страницы, часы, авторизацию, API, документы или персональные данные.
- Ссылка «Установить» в верхнем меню и страница /install с инструкциями iPhone/Android и кнопкой установки при поддержке браузером.
- Standalone PWA открывается на / и сохраняет существующую авторизацию Supabase.

## Установка
1. Скопируйте файлы v0.32 в корень репозитория standel-time, сохраняя каталог public и app.
2. GitHub Desktop: Commit to main → Push origin.
3. Railway: Deployments → Success / Active.
4. На телефоне откройте https://time.standel.se/install в Safari (iPhone) или Chrome (Android).
5. Установите PWA и проверьте вход пользователя; приложение требует интернет.

## Безопасность и ограничения
- Никакого офлайн-режима записи часов, push-уведомлений и публикации в App Store/Google Play.
- При очистке данных браузера может потребоваться повторный вход.
- Реальную установку на iOS/Android нужно проверить на устройствах.
- Новых секретов, SQL-миграций и изменений RLS нет.
