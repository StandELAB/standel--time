# StandEL Time v0.24 — контроль сроков сертификатов

Обновление поверх v0.23. **Новых SQL-миграций нет.** Миграция 007 должна быть установлена заранее.

## Изменения
- В разделе администратора «ID06 / сертификаты» появились счётчики просроченных сертификатов и истекающих через 30/60 дней.
- Фильтр по сроку действия, сортировка по ближайшей дате окончания, цветовой индикатор и экспорт отфильтрованного списка в Excel / печать в PDF.
- Новые записи с датой окончания добавляются через существующую форму.

**Важно:** файл, загруженный сотрудником в «Личные данные», пока не содержит поля даты окончания. Такие файлы исключены из мониторинга, пока администратор отдельно не создаст связанную по смыслу запись в таблице `certificates`. Автоматические сообщения и серверное расписание в эту версию не входят.

## Развёртывание
1. Сохраните предыдущий архив v0.23.
2. Скопируйте содержимое этого архива в корень GitHub-репозитория `standel-time`.
3. Commit to main → Push origin. Дождитесь успешной сборки Railway.
4. Проверьте раздел ID06 / сертификаты под администратором и экспорт.

Резервное копирование рабочей базы пока не настроено: не вносите рискованные ручные SQL-изменения.
