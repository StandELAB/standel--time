# StandEL Time v0.23 — шведский формат календаря

Обновление поверх v0.22. В календаре администратора и работника неделя отображается с понедельника (Mån) по воскресенье (Sön); слева показывается номер недели `v.N` по ISO 8601. Недели на границе года рассчитаны по ISO, поэтому 29–31 декабря могут относиться к первой неделе следующего года.

Новые таблицы и SQL-миграции не нужны. Изменены `app/components/sweden-calendar.tsx`, панели и `app/globals.css`. При применении к production предварительно завершите миграцию 007, если ещё не выполнили её для версии v0.22, поскольку v0.23 включает функционал v0.22.

Проверить: декабрь 2026 (`v.49`–`v.53`) и январь 2027 (начинается с `v.53`, далее `v.1`); дни 1–7 расположены под правильными заголовками. Важно: номера недели не относятся к календарному году месяца, а соответствуют ISO week-year.
