# StandEL Time v0.26 — недельные и объектные сводки

Версия основана на v0.25. **Новых миграций SQL не требуется**. Миграция 008 из v0.25 должна быть установлена ранее.

## Новое

- В личном календаре работника показаны недельные суммы часов в формате ISO 8601: неделя v.N, ISO-год, количество дней с записью, сумма часов и категория Övertid.
- Таблица суммарных часов по объектам, с кодами проектов.
- Две отдельные выгрузки Excel (.xlsx) — по неделям и по объектам за выбранный месяц.
- На небольших экранах таблицы прокручиваются по горизонтали.

**Границы расчётов:** недели считаются по ISO, но показаны только записи выбранного календарного месяца (не целая переходящая неделя). Дни — уникальные даты с часами, не подтверждение посещаемости. Övertid — категория записи, без начисления зарплаты. Выборка унаследована от v0.25 и может быть ограничена — для расчёта зарплаты сверяйте с базой.

## Установка

1. Сохранить файлы версии v0.25 для отката; резервное копирование базы пока не настроено.
2. Скопировать содержимое архива v0.26 в корень GitHub репозитория `standel-time`, commit и push в `main`.
3. Дождаться `Success / Active` в Railway.
4. Под тестовым электриком открыть «Календарь», выбрать месяц с часами. Сверить сумму недель с суммой за месяц, скачать оба Excel.
5. Проверить границу года на тестовых записях (неделя 1 может относиться к следующему ISO-году).
