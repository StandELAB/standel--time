# StandEL Time v0.27 — создание объектов и кнопка «Главная»

## Изменения
- В форме создания объекта добавлены «Заказчик», «Город объекта», «Адрес объекта».
- Список объектов и Excel/PDF-экспорт включают эти поля.
- Для существующих объектов добавлена кнопка «Заказчик / адрес».
- Кнопки «Главная» в верхней навигации и на логотипе открывают домашнюю вкладку активного кабинета через `/`; пользователь не выходит из системы.
- Незалогиненные пользователи по-прежнему видят публичную стартовую страницу.

## Установка
1. В рабочем Supabase SQL Editor выполнить `sql/009_project_location.sql`.
2. Проверить, что `public.projects` содержит `site_address`, `site_city`.
3. Скопировать исходники v0.27 в репозиторий GitHub и выполнить Commit → Push.
4. Дождаться Success / Active на Railway.
5. Проверить создание объекта, экспорт и кнопку «Главная» из кабинета администратора и сотрудника.

## Важно
- Поле `client_name` (заказчик) уже существовало, данные не удаляются.
- Резервное копирование рабочей базы пока не настроено; желательно сохранить копию перед миграцией.
- Приложение требует действующие политики RLS на projects; новая миграция их не меняет.
