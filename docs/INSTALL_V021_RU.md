# StandEL Time v0.21 — обновление

Изменения: всплывающее окно календаря с сотрудниками/причинами и экспортом Excel/PDF (через печать браузера); тематический фон на всех страницах; кнопка Выход вместо Вход для авторизованных пользователей; экспорт сертификатов Excel/PDF; обязательный выбор конкретного сотрудника для контроля табелей.

Новая SQL миграция не требуется. Развёртывание: скопировать содержимое папки в репозиторий, Commit → Push → Railway. Перед установкой сохранить исходники v0.20 для отката.

Важно: PDF формируется через стандартное окно печати браузера «Сохранить как PDF». Календарные записи и отчёты основаны на загруженной в панель выборке (до 200 записей отсутствий): для полного исторического экспорта нужен серверный отчёт с пагинацией. Бэкап рабочей базы пока не настроен.
