# StandEL Time v0.25 — установка

1. Перед установкой сделать резервную копию базы (резервирование на Free пока не настроено).
2. В рабочей базе Supabase выполнить `sql/008_employee_names.sql` в SQL Editor. Миграция добавляет `first_name` и `last_name` к `public.employee_personal_details` без удаления существующих данных.
3. Загрузить исходники v0.25 в GitHub `main` и дождаться `Success / Active` Railway.
4. Проверить: личные данные → имя и фамилия → сохранить → обновить страницу; календарь сотрудника → нажать дату с часами → проверить объект и описание.
5. Проверить изменения на мобильном устройстве и права RLS под тестовым пользователем.

Поля имени и фамилии редактируются в личном профиле. Они намеренно не меняют `org_members.display_name` автоматически: обновление отображаемого имени во всех рабочих отчётах — отдельная операция администратора.
