# StandEL Time v0.16 — онлайн-обновление

Обновляется проект Next.js v0.9, а не локальный index.html v0.15. Сохранены серверные маршруты авторизации и существующие таблицы Supabase.

## Безопасный порядок
1. Создать приватную резервную копию базы Supabase до изменений.
2. Внести файлы из этого архива в закрытый репозиторий `StandELAB/standel-time` с сохранением структуры (package.json должен быть в корне). Не загружать секреты или файлы .env.local.
3. В Supabase SQL Editor выполнить ТОЛЬКО `sql/004_online_reports_absences.sql`. Файлы 001–003 уже выполнялись и повторять их не нужно.
4. Railway автоматически запускает новую сборку из GitHub. Проверить Build Logs и статус Active.
5. Проверить `/admin`: «Часы работников», «Календарь», «Работники / доступ» и назначения на странице объектов.
6. В приватном окне войти тестовым сотрудником и обновить `/employee`. Если объект отсутствует, посмотрите текст диагностического сообщения, затем сверьте таблицы `org_members`, `project_assignments`, `projects` для того же org_id и user_id.

## Важные ограничения
- PDF реализован через стандартную печать браузера → Save as PDF. Excel-совместимый экспорт — CSV UTF-8 с разделителем `;`, а не XLSX.
- Данные на странице администратора пока ограничены 500 записями времени (`app/admin/page.tsx`); полный месячный отчёт для крупной базы потребует серверной пагинации.
- Это промежуточное онлайн-обновление, а не полное портирование всех элементов демо v0.15: аватары, разграничение вкладок с назначениями бригадиров, экспорт XLSX и все отчёты по операциям ещё должны быть реализованы и проверены.
- До проверки RLS и разграничения ролей не запускать для реальных сотрудников.
