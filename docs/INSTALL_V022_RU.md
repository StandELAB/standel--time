# StandEL Time v0.22 — личные данные и сертификаты

**ВНИМАНИЕ: Требуется новая миграция `sql/007_personal_profiles_certificate_files.sql`.**

1. Сохраните предыдущий ZIP v0.21 и по возможности независимую копию базы Supabase.
2. На рабочем проекте Supabase в SQL Editor выполните весь файл `sql/007_personal_profiles_certificate_files.sql`. Убедитесь, что нет ошибок.
3. Проверьте, что `employee_personal_details`, `employee_certificate_files` включают RLS, а bucket `standel-certificates` имеет `public=false`.
4. Затем скопируйте содержимое архива v0.22 в GitHub Desktop `standel-time`, сделайте Commit и Push. Railway автоматически пересоберёт сайт.
5. Войдите под тестовым сотрудником → «Личные данные», проверьте изменение фото и сохранение тестового телефона, загрузите небольшой тестовый PDF и скачайте его.
6. Отдельно проверьте, что другой работник не видит личные сведения/файлы через API. Администратор просматривает прикреплённые файлы в разделе «ID06 / сертификаты»; их содержимое доступно только уполномоченным пользователям.

Допустимые форматы: PDF, JPG, PNG, WebP, GIF, HEIC, HEIF, DOC, DOCX, XLS, XLSX, ODT, ODS, TXT, CSV (макс. 15 МБ). Нельзя гарантировать безопасность или просмотр произвольных форматов.

Файлы хранятся в Supabase Storage и НЕ входят в обычный SQL-дамп базы. Резервное копирование по-прежнему важно.
