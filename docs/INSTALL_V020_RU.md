# StandEL Time Online v0.20 — установка

## Изменения

- У бригадира в «Моя бригада» появилась помесячная сводка часов назначенных сотрудников. Данные загружаются по нажатию кнопки через Supabase с текущими правами RLS.
- Отображаются часы, число дней с записями и запланированные прошедшие смены без часов. Это предварительная сверка, не автоматическое определение прогулов.
- Экспорт сводки бригады в Excel.
- В «Контроль табелей» администратор может скопировать индивидуальное напоминание сотруднику. **Ничего не отправляется автоматически.**

## Развёртывание

1. SQL-миграции для v0.20 не требуются.
2. Сохрани архив v0.19 для отката, затем перенеси содержимое v0.20 в корень GitHub `standel-time`.
3. Commit → Push origin, дождись Railway Success / Active.
4. Администратор: открой «Контроль табелей», проверь копирование напоминания.
5. Под бригадиром: «Моя бригада» → выбор месяца → «Показать часы команды». Проверь чтение только назначенных работников.

## Ограничения

- Вкладка бригадира использует запросы с лимитом 1000 строк на месяц; предупреждает при достижении лимита.
- Для чтения часов команды действующие политики Supabase обязаны разрешать бригадиру видеть работников своей бригады. Если выдаётся ошибка RLS, не ослабляй политику без проверки.
- Подсказки о пропущенных днях в админке используют загруженную выборку данных и могут быть неполными.
- Уведомления через email/SMS и автоматическое расписание отсутствуют; это отдельный этап.
- Резервные копии Supabase пока не настроены; перед рискованными изменениями создай отдельную копию данных.
