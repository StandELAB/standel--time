# StandEL Time v0.33 — восстановление вкладки «Работники / доступ»

## Исправленная проблема
В v0.31 при изменении административной панели был удалён JSX-блок, который отображал вкладку «Работники / доступ»; v0.32 унаследовала эту ошибку. Таблицы Supabase не удалялись из-за этого изменения интерфейса.

## Исправление
- Возвращена вкладка со списками действующих и архивных работников.
- Возвращено управление ролями, бригадирами, дополнительными вкладками, архивированием, восстановлением и безопасным удалением работников.
- Под каждым сотрудником список выбранных им объектов отображается без администраторских кнопок назначения; электрики выбирают объекты самостоятельно.
- Сохранены изменения PWA v0.32, недельные часы и прочие функции.

## Установка
Новая SQL-миграция не нужна. Скопировать исходники в GitHub `standel-time` (ветка `main`), Commit и Push, затем проверить Railway. Обновить страницу администратора и открыть «Работники / доступ».

Важно: новая версия не меняет данные пользователей, настройки RLS или таблицы. Если список пуст даже после развёртывания, проверить `org_members` и права выборки в Supabase.
