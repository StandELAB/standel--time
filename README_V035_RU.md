- Администратор: заголовок «StandEL Time», без слова «Администрация».
- Вместо множества кнопок разделов — единое выпадающее меню без отдельной метки «Раздел».
- Карточки главной страницы «Сотрудников», «Объектов», «Часы за период» ведут в соответствующие разделы.

- Кнопка «Выход» выравнивается вправо в верхней панели, включая мобильный экран.
- Логика авторизации, архивирования работников и база Supabase не менялись.

Для установки: заменить файлы репозитория, Commit to main → Push origin, дождаться Success/Active в Railway. После развёртывания проверьте основные разделы и выход на iPhone.
