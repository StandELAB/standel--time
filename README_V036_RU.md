# StandEL Time v0.36 — формулы электрика

На главной странице кабинета сотрудника добавлена карточка «Формула дня для электрика» с библиотекой из 8 проверенных базовых формул: закон Ома, мощность однофазной и симметричной трехфазной цепи, энергия, сопротивление проводника и соединения резисторов. При открытии кабинета карточка выбирает формулу случайно; кнопка «Другая» показывает новую. В карточке есть расшифровка переменных и пример с единицами измерения.

Показывается только в кабинете работника. Существующие разделы, права, данные и учёт часов не меняются. SQL-миграция не нужна. Достаточно заменить исходники, выполнить Commit и Push в GitHub Desktop и дождаться нового деплоя Railway.

Обратите внимание: формулы иллюстративны и не заменяют профессиональные электротехнические расчёты, проверку защит и требования применимых стандартов.
