# StandEL Time v0.9 (Next.js + Supabase)

В этой версии добавлены **Material (материалы)**, **Dagbok (дневник с фотографиями)** и **ÄTA (дополнительные работы)**, связанные с проектами и Arbetsorder. Это собственный код StandEL, а не копия NEXT.

## Где что находится

- `app/admin` — административная панель; новая вкладка «Material / Dagbok / ÄTA».
- `app/employee` — персональный кабинет; новая панель «Работа на объекте».
- `app/components/site-operations.tsx` — новый общий интерфейс модулей с проверкой роли на базе.
- `sql/003_material_diary_ata.sql` — новые таблицы, политики доступа, приватный бакет фотографий.
- `docs/MATERIAL_DAGBOK_ATA_RU.md` — инструкция обновления и тестирования.
- `legacy_v06` — старый локальный прототип для сравнения; он не содержит v0.9 функций.

## Минимальный порядок запуска

Создать Supabase → применить SQL 001, 002, 003 по порядку → настроить `.env` → `npm install` → `npm run typecheck` → `npm run build` → развернуть на Vercel или Railway → привязать `time.standel.se`. Вход администратора и приглашения работников требуют отдельной первоначальной настройки из `docs/DEPLOY_RU.md`.

Это **проектная версия исходного кода**, а не работающий без настройки серверов сайт. Тест полного сценария в облаке не выполнялся. Не используйте его для боевого учёта часов до проверки сохранения данных, ролей и резервных копий.
