# StandEL Time — обновление серверной версии v0.16 (тестовая)

В отличие от `StandEL_Time_v015_Preview.zip`, это Next.js-приложение для Railway и Supabase.

**Перед установкой** прочитайте `docs/ONLINE_UPGRADE_RU.md`. Сначала сделайте резервную копию базы.

Сохранены: авторизация OTP, базовые проекты и назначения, графики, Arbetsorder, Material, Dagbok, ÄTA и учёт времени.

Добавлены: админская «Главная», «Часы работников» с фильтром по месяцу и объекту, «Работники / доступ», назначение прямо на странице объекта, календарь отпусков/больничных/невыходов, их регистрация администратором, печать PDF, CSV для Excel.

Ограничения: не все функции локального прототипа v0.15 перенесены. Аватарки и индивидуальные разрешения на вкладки ещё не реализованы в этой серверной сборке; экспорт Excel — CSV, не XLSX. Нужны тесты на Railway с настоящей Supabase и ревизия RLS перед работой с данными сотрудников.

В СУЩЕСТВУЮЩЕМ Supabase выполнить только `sql/004_online_reports_absences.sql`; НЕ запускать 001–003 повторно.
