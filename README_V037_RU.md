# StandEL Time v0.37 — умная главная администратора

Новая главная страница администратора. Все существующие разделы остаются в выпадающем меню.

- KPI: действующие сотрудники и активные объекты; зарегистрированные часы за дату и текущую ISO-неделю.
- Отсутствия за выбранную дату и список причин.
- Рабочие объекты с часами за выбранную дату, с числом сотрудников по зарегистрированным записям.
- Возможные пропущенные запланированные смены без часов с учётом отмеченных отсутствий.
- Число просроченных и истекающих в ближайшие 30 дней сертификатов (с указанной датой окончания).
- Переходы на действующие страницы «Сотрудники», «Объекты», «Часы работников», «Отсутствия», «Графики», «Контроль табелей», «Сертификаты».
- Ручное обновление и выбор даты. Данные часов, отсутствий и смен запрашиваются у Supabase за нужную ISO-неделю, не из последних 500 строк.

Сводка отражает регистрацию часов, а не физическое присутствие; неполные табели могут давать искажённые показатели. Если выбранная неделя содержит более 10 000 записей или отсутствий, появляется предупреждение о неполной выборке.

Новых SQL-миграций нет. Установить: скопировать содержимое архива в текущий GitHub-репозиторий, commit, push, дождаться Railway Success / Active.

Рекомендация: перед массовым вводом реальных данных настроить независимое резервное копирование Supabase.
