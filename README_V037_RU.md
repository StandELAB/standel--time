# StandEL Connect v1 / StandEL Time v0.37

Первый этап: API GET /api/v1/hours?year=2027 и страница /admin/connect. SQL не нужен. Архив 2026 не меняется. API отдаёт только часы одной заданной организации; не отдаёт зарплаты, персональные номера, описания, ключи Supabase. Исключает удалённые записи. Статус payroll_status относится к месяцу сотрудника, не к отдельной записи. Выгрузка всех часов, включая неподтверждённые. При ошибке БД возвращается 503, не пустой успешный ответ. При параллельных изменениях выгрузка не является транзакционным снимком; для окончательного расчёта сначала подтвердить табели.

## Установка
1. Сделать резервную копию исходников и базы. Заменить исходники в GitHub Desktop, не заменять локальный .env.local. Не удалять существующие переменные Railway.
2. В существующем проекте Railway добавить STANDEL_CONNECT_ORG_ID (UUID из /admin/connect после деплоя или таблицы organizations Supabase) и STANDEL_CONNECT_KEY (случайный пароль минимум 32 символа; в Terminal: openssl rand -hex 32). Не добавлять ключ в Git или Excel-формулу.
3. npm install, npm run typecheck, npm run build; Commit/Push и проверить деплой. Войти администратором и открыть «Интеграция с Excel».
4. Проверка без авторизации: URL должен вернуть 401; до настройки — 503. Проверка с авторизацией: curl --user standel 'https://time.standel.se/api/v1/hours?year=2027' (curl спросит пароль). Только HTTPS. Сравнить часы с отчётом сайта за тот же период, включая сверхурочные и архивных сотрудников. Проверить удаление/исправление записи и пустой год. Не передавать пароль в чат.
5. Excel: Power Query — пустой запрос, расширенный редактор, вставить текст из StandEL_Connect_PowerQuery.m. При запросе credentials выбрать Basic, логин standel, пароль из Railway. Если версия Excel Mac не поддерживает Basic для Web.Contents, потребуется другой способ импорта. Не сохранять пароль в тексте запроса. Загрузить результат на отдельный лист. Refresh All заменяет снимок, а не добавляет записи. Не включать обновление закрытых зарплат до реализации локальных снимков. Сопоставление ID с существующей книгой, тарифы и оплачиваемые клиентом часы — следующий этап; текущий запрос не изменяет журнал или финансовые формулы.

Проверки сборки и реального подключения должны быть выполнены перед использованием в production. Для отключения удалить STANDEL_CONNECT_KEY из Railway.
